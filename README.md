# Sales-Performance-Dashboard
Recommended Structure and order
Regional Sales Performance Dashboard | Power BI
This project turns raw sales, product and returns data into an interactive Power BI dashboard. I cleaned the data in Power Query, built a data model and DAX measures, and analyzed performance across 5 Canadian regions. The goal was to understand why West region sales fell 46% from Q1 to Q2 2026, even though the number of orders went up.
Tech Stack. Power BI Desktop for building the report and interactive dashboard, Power Query (M language) for data cleaning, conditional columns and a custom discount function, DAX for measures like Total Sales, Net Sales, Average Order Value and West Region Sales, using CALCULATE, DIVIDE and RELATED, Data modeling to connect the Sales, Products and Returns tables with relationships and Microsoft Excel and CSV as the raw data sources
